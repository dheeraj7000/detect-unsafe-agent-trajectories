GraphGuard

Early Warning of Unsafe Long-Horizon Agent Behavior from Partial Execution Graphs

Can graph-based representations detect unsafe long-horizon agent behavior earlier than ordinary trajectory classifiers? GraphGuard builds an instrumented agent-control testbed and tests whether partial typed execution graphs provide earlier, better-calibrated warning of unsafe behavior than sequence-based trajectory classifiers, while preserving useful task performance.

Status: Research & open-source artifact Tests: 34 passing License: MIT Repo: dheeraj7000/detect-unsafe-agent-trajectories

Overview

A falsifiable study of graph- vs sequence-based early warning for unsafe agent trajectories.

Central Question

At matched false-positive rate and task utility, does a graph-based monitor detect an unsafe trajectory at a smaller fraction of the episode than strong sequence baselines?

Core Hypothesis

Long-horizon agent failures are often relational rather than local: a tool call may be harmless alone but risky when connected to an untrusted input, sensitive resource, privilege change, memory update, or later external action. A typed temporal graph exposes these dependencies explicitly.

Decision Rule

Support the hypothesis only if the graph monitor produces statistically meaningful earlier detection at matched FPR, without materially reducing benign task utility, and the advantage persists on unseen scenarios or longer horizons. If accuracy improves but lead time does not, the central hypothesis is not supported.

Why Now

Frontier agents are achieving increasingly long autonomous task horizons (METR). AgentDojo and AgentDyn show tool-using agents remain vulnerable to indirect prompt injection and complex dynamic attacks. Existing graph-based work (AgentArmor) supports policy enforcement but leaves open the question of predictive lead time on partial, long-horizon traces.

Method

The Agent Control & Evaluation Lab and the proposed graph monitor.

Agent Control & Evaluation Lab

An open-source sandbox for running tool-using agents against benign and adversarial long-horizon tasks. The same harness records raw trajectories and constructs behavior graphs online, allowing apples-to-apples comparison between monitoring approaches.

  • MCP-compatible tool gateway with identity & policy engine
  • Dockerized tool sandbox (email, files, web, code, mock APIs)
  • OpenTelemetry-style event schema + JSONL/Parquet trace store
  • Deterministic replay (fixed seeds, immutable scenario manifests)
  • Online typed behavior-graph builder

Graph Monitor

A temporal graph neural network that scores risk after every action using graph features from the partial behavior graph. Unlike sequence baselines, it sees explicit provenance, authorization, and dependency edges.

  • Typed nodes: goal, tool_call, credential, memory_write, policy_decision, external_effect, …
  • Typed edges: follows, derived_from, reads, writes, authorizes, invokes, sends_to, …
  • Temporal GNN: node/edge embeddings, typed message passing, mean-pooling readout, sigmoid risk head
  • Risk score emitted after every observed action

Behavior Graph Schema

Typed nodes and edges that make relational dependencies explicit.

Node Types

goal · subgoal · observation · instruction · tool_call · tool_result · file_resource · credential · memory_write · memory_read · policy_decision · user_approval · external_effect

Edge Types

follows · derived_from · reads · writes · authorizes · invokes · depends_on · contradicts · escalates_privilege · sends_to · persists_to_memory

Example Risk Pattern

untrusted tool output → plan update → credential read → external send. A flat sequence model must infer the dependency across distance; the graph makes the provenance and sensitive-data path explicit.

Key Ablations

  • Remove provenance / authorization / temporal edges
  • Untype nodes & edges
  • Full graph vs bounded recent subgraph
  • Train on one attack family, test on unseen
  • Counterfactual replay (remove permission / sanitize output)
